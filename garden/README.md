# garden (app)

Aplicação Next.js 16 (App Router) do site da Garden Psychedelia.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run start
npm run lint     # oxlint
```

Documentação completa (estrutura, Docker, variáveis de ambiente, temas) no
[README da raiz do repositório](../README.md).
